# 思政与C语言课程知识智能答疑系统 (AI-QA-web-v2)

## 项目介绍
本项目为“传智杯”参赛作品，针对大一学生思政与C语言课程痛点，打造轻量级智能答疑系统。系统支持高频知识点极速响应与复杂问题AI泛化解答，前端采用毛玻璃（Glassmorphism）视觉设计，后端实现高可用排障机制，保障“零假死”交互体验。

## 技术架构
- **前端**：原生 HTML/CSS/JS，CSS `backdrop-filter` 毛玻璃质感 UI
- **后端**：Python Flask，Gunicorn 生产级部署
- **AI双引擎**：本地 JSON 高频匹配（极速） + 火山方舟 API（泛化兜底）
- **安全与排障**：API 密钥 `.env` 后端封装，AbortController + 超时处理防假死

## 核心亮点
- **双引擎策略**：兼顾毫秒级响应与教材深度答疑
- **工程排障**：攻克 Flask 阻塞与前端挂起，稳定部署
- **现代UI**：毛玻璃设计，兼顾美观与可读性
- **安全封装**：环境变量管理，保障调用安全
